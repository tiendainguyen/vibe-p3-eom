# Initial Project Skill

## Purpose
Bootstrap the runnable Spring Boot skeleton from the SRS — so that every subsequent `/feat-apply` task starts from a real, compiling, testable base rather than an empty folder.

The output is a project that:
- Compiles with `./mvnw compile`
- Starts with `./mvnw spring-boot:run` (may fail if DB not running — that is acceptable)
- Has all package directories created
- Has all external dependencies declared in `pom.xml`
- Has placeholder `application.yml` wired to environment variables
- Has `GlobalExceptionHandler`, `ErrorResponseDTO`, and `SecurityConfig` in place

---

## Instructions

### Phase 1: Read Requirements
1. Read `docs/SRS.md` — extract: project name, base package, tech stack, integrations, user roles
2. Read `docs/TASK_BREAKDOWN.md` — note all feature tasks and their IDs
3. Read `CLAUDE.md` — note naming conventions and code style
4. Read `.claude/rules/security.md` — apply security rules to all generated files

Derive the following from SRS:
- **Base package**: e.g. `com.example.ecommerce` (use project name in kebab-case → reverse domain)
- **Dependencies needed**: from integrations section (PostgreSQL, Redis, RabbitMQ, Stripe, etc.)
- **User roles**: from stakeholders section (USER, ADMIN, etc.)
- **Auth mechanism**: JWT or session (always JWT for REST APIs unless SRS says otherwise)

### Phase 2: Create pom.xml
Write `pom.xml` at project root with:

**Spring Boot parent**: `3.x.x` (latest stable)
**Java version**: `21`
**Required starters** (always include):
- `spring-boot-starter-web`
- `spring-boot-starter-data-jpa`
- `spring-boot-starter-security`
- `spring-boot-starter-validation`
- `flyway-core` + `flyway-database-postgresql`

**Conditional — add based on SRS integrations**:
- PostgreSQL: `postgresql` driver
- Redis: `spring-boot-starter-data-redis`
- RabbitMQ: `spring-boot-starter-amqp`
- Email: `spring-boot-starter-mail`
- JWT: `jjwt-api`, `jjwt-impl`, `jjwt-jackson` (io.jsonwebtoken)
- Stripe: `stripe-java`
- MapStruct: `mapstruct` + `mapstruct-processor`
- Lombok: `lombok`

**Test scope**:
- `spring-boot-starter-test`
- `h2` (test scope — for `@DataJpaTest`)

**Plugins**:
- `spring-boot-maven-plugin`
- `maven-compiler-plugin` with annotation processors for Lombok + MapStruct

#### GlobalExceptionHandler.java
```java
package <basePackage>.config;

import <basePackage>.dto.ErrorResponseDTO;
import jakarta.persistence.EntityNotFoundException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.stream.Collectors;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponseDTO> handleValidation(MethodArgumentNotValidException ex) {
        String message = ex.getBindingResult().getFieldErrors().stream()
                .map(FieldError::getDefaultMessage)
                .collect(Collectors.joining(", "));
        return ResponseEntity.badRequest()
                .body(ErrorResponseDTO.of(400, "Validation Failed", message));
    }

    @ExceptionHandler(EntityNotFoundException.class)
    public ResponseEntity<ErrorResponseDTO> handleNotFound(EntityNotFoundException ex) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(ErrorResponseDTO.of(404, "Not Found", ex.getMessage()));
    }

    @ExceptionHandler(IllegalStateException.class)
    public ResponseEntity<ErrorResponseDTO> handleIllegalState(IllegalStateException ex) {
        return ResponseEntity.status(HttpStatus.CONFLICT)
                .body(ErrorResponseDTO.of(409, "Conflict", ex.getMessage()));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponseDTO> handleGeneral(Exception ex) {
        return ResponseEntity.internalServerError()
                .body(ErrorResponseDTO.of(500, "Internal Server Error", "An unexpected error occurred"));
    }
}
```

#### SecurityConfig.java
Write a skeleton that:
- Disables default form login
- Permits public endpoints (GET /api/products/**, /api/auth/**)
- Requires authentication for everything else
- Is stateless (no sessions)
- Has a placeholder comment `// TODO: add JWT filter in T-XXX (Auth task)`
- Includes `BCryptPasswordEncoder` bean
- Uses `@EnableMethodSecurity` for future `@PreAuthorize` usage

```java
package <basePackage>.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**", "/api/products/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            );
        // JWT filter will be added in the Auth feature task
        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

## Anti-patterns to Avoid
- Never hardcode secrets, passwords, or API keys in `application.yml` — always `${ENV_VAR}`
- Never set `ddl-auto: create` or `update` in the main `application.yml` — use Flyway only
- Never write business logic in config classes
- Never add `@Component` or `@Service` to config classes (use `@Configuration` + `@Bean`)
- Never skip `@EnableMethodSecurity` — admin endpoints rely on it
- Never generate a full implementation of features here — this skill creates the base skeleton only
