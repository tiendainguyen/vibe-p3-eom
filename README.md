# p3-eom

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A real-time collaboration tool for engineering teams

**Stack:** Spring Boot 3 + Java 21

---

## Quick Start

```bash
./mvnw dependency:resolve     # Install dependencies
./mvnw spring-boot:run         # Dev server → http://localhost:8080
```

## Commands

```bash
./mvnw test        # Run tests
./mvnw package -DskipTests       # Production build
./mvnw verify        # Lint + auto-fix
```
